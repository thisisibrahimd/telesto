# AGENTS.md

## Toolchain

- `mise` manages tool versions: Go 1.25.8, golangci-lint 2.6.1 (see `.mise.toml`)
- `just` is the task runner (not `make`) — see `justfile` at repo root
- `goreman` orchestrates local services via `procfile`
- `direnv` loads `.envrc` for env vars (`TELESTO_INITIAL_USERNAME`, `TELESTO_INITIAL_PASSWORD`, `KUBECONFIG`, `KO_DOCKER_REPO`)

## Commands

| Task | Command |
|---|---|
| Run all services | `just start` (goreman with procfile) |
| Live-reload dev | `just start-live` (reflex watches `.go`, excludes `templates/`) |
| Run tests | `just test` (`go test -v ./...`) |
| Generate OpenAPI spec | `just gen-api` (Jsonnet → YAML) |
| Generate server stubs + spec | `just gen-server` (runs gen-api then oapi-codegen) |
| Generate DB query layer | `just gen-query` (`go generate` → gorm/gen) |
| Generate API client | `go generate ./internal/client/lib/apiclient/...` |
| Generate templ HTML | `templ generate` (auto-run by `just start-server`) |
| Build release artifacts | `just build` (goreleaser) |
| Run CLI client | `just client <args>` |

## Code Generation

Multiple codegen pipelines — run the right one after changing a source:

- **OpenAPI spec**: Edit `api/api.jsonnet` → `just gen-api` → produces `api/api.yaml`
- **Server stubs**: `just gen-server` runs `gen-api` then `go generate ./internal/server/api/...` (oapi-codegen with `api-srv.gen.yaml`)
- **API client**: `go generate ./internal/client/lib/apiclient/...` (oapi-codegen with `api-gen.yaml` against `api/api.3-0.yaml`)
- **DB queries**: Edit models in `internal/storage/model/` → `just gen-query` (gorm/gen)
- **Templ templates**: Edit `.templ` files in `templates/` → `templ generate`

## Do Not Edit (generated files)

- `api/api.yaml` — generated from `api/api.jsonnet`
- `internal/storage/query/gen.go`, `otelcols.gen.go` — generated by gorm/gen
- `internal/client/lib/apiclient/client.gen.go` — generated by oapi-codegen
- `templates/**/*_templ.go` — generated by templ from `.templ` sources

## Architecture

- **Two binaries**: `cmd/telesto-server` (web server) and `cmd/telestoctl` (CLI client)
- **Router**: chi/v5 with Ory Kratos session middleware
- **Auth**: Ory Kratos (external service, not in-app) — config in `kratos.yml`
- **Storage**: GORM over rqlite (not Postgres/MySQL) — models in `internal/storage/model/`, generated queries in `internal/storage/query/`
- **Templates**: templ (`.templ` files in `templates/`) for server-rendered HTML, not `html/template`
- **DI**: uber/fx (see `go.mod`)
- **Web routes**: defined in `internal/server/web/web.go`, implementations in `internal/server/web/impl.go`
- **Deploy**: Tanka (Jsonnet) for Kubernetes in `deploy/`, GoReleaser + ko for container images to `quay.io/telesto`

## Local Development

Services required (launched by `just start` via goreman):

| Service | Port | Start command |
|---|---|---|
| rqlite (database) | 4001 | `just start-db` |
| Ory Kratos (auth) | 4433 (public), 4434 (admin) | `just start-auth` |
| Telesto server | 9000 | `just start-server` |

Init sequence when starting fresh:
1. `just start-db` then `just wait-for-db`
2. `just start-auth` then `just init-auth` (waits for Kratos, seeds default users from `default-users.json`)
3. `just start-server` (runs `templ generate --watch` then `go run` with `--migrate`)

The server auto-migrates the DB schema when started with `--migrate`.
